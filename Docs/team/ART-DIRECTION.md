# ART-DIRECTION — "테이프/방송 세계"

> 아트 방향 확정 문서 (2026-07-25). 이후 모든 에셋·이펙트·UI는 이 문서의 팔레트와 시각 문법을 따른다.
> 관련: [GDD.md](GDD.md) §아트 스타일 (기존 "[미결정]" 항목을 본 문서가 대체)

## 1. 콘셉트

**세계 전체가 녹화 매체다.** 클론은 재생 중인 테이프 유령, 녹화는 REC, 되감기는 VHS 노이즈.
"레코드-앤-리플레이" 메커닉 자체를 시각 정체성으로 사용한다 — 스크린샷 한 장으로 "녹화 게임"이 전달되는 것이 목표.

### 원칙
- **베이스는 플랫 도형 유지** — 텍스처 디테일로 승부하지 않는다. 차별화는 셰이더/포스트 프로세싱/연출 레이어에서.
- **가독성 > 이펙트** — 화면에 클론 4~5개가 동시 재생된다. 어떤 이펙트도 정체성 판별과 판정 인지를 해치면 안 된다.
- **폴리시 예산은 "전 클론 동시 재생" 하이라이트에 몰아준다.**

## 2. 팔레트

### 정체성 4색 (게임플레이 전용)

| 정체성 | 확정값 (hex) | RGB float | 현재 에셋값 | 명도 사다리 |
|---|---|---|---|---|
| 무거운형 (Heavy) | `#4F63D2` 인디고 | (0.31, 0.39, 0.82) | (0.12, 0.16, 0.45) | 1 (가장 어두움) |
| 벽타기형 (Climber) | `#C878F0` 마젠타 퍼플 | (0.78, 0.47, 0.94) | (0.6, 0.4, 0.85) | 2 |
| 운반형 (Carrier) | `#FFAD33` 앰버 | (1.0, 0.68, 0.2) | (0.3, 0.7, 0.35) | 3 |
| 가벼운형 (Light) | `#6FE6D4` 민트 시안 | (0.44, 0.9, 0.83) | (0.45, 0.8, 1.0) | 4 (가장 밝음) |

**선정 기준** (팔레트 변경 시에도 이 기준을 유지할 것):
- 어두운 배경(`#101318`) 위에서 **알파 0.5(클론 상태)로도 4색이 상호 구별**되어야 한다.
- 색상(hue)만이 아니라 **명도 사다리로도 구분** — 색각이상 대응. 4색의 명도가 전부 달라야 한다.
- 기존값 대비 변경 이유: 현재 무거운형(네이비)·가벼운형(하늘색)이 같은 파랑 계열이라 혼동 위험 + 네이비는 어두운 배경에서 침몰. 운반형은 가벼운형(민트)과의 충돌을 피해 초록 → 앰버로 이동.

### 환경 색 (저채도 — 정체성 4색과 절대 겹치지 않게)

| 용도 | 값 | 비고 |
|---|---|---|
| 배경 원경 | `#101318` | 근-흑 청회색. CRT 꺼진 화면 톤 |
| 지형/구조물 (Ground) | `#2A303B` | 저채도 회청 |
| 정체성 게이트 요소 | 해당 정체성 색의 **저채도 50% 톤** | Climbable 벽 = Climber 톤, IdentityPortal = 허용 정체성 톤. 어포던스를 팔레트로 통일 |

| 용도 | 값 | 비고 |
|---|---|---|
| REC 레드 | `#FF3B30` | 녹화 상태 전용. 게임플레이 오브젝트에 사용 금지 |

## 3. 상태별 시각 문법

| 상태 | 표현 | 구현 레이어 |
|---|---|---|
| **라이브 (조작 중)** | 불투명(α=1.0), 선명, 이펙트 없음 | 기존 구현 그대로 |
| **클론 (재생 중)** | 반투명(α=0.5, `CloneAlpha`) + 스캔라인 + 밝기 미세 지터 | Step 2: 스프라이트 셰이더 |
| **녹화 중** | 화면 구석 `REC●` 오버레이(1Hz 점멸) + 가장자리 붉은 비네트(약하게) | Step 2: UI + Volume |
| **되감기 / undo** | VHS 노이즈 플래시 0.2~0.3초 + 색수차 순간 강화 | Step 3: Full Screen Pass |
| **클리어 동시 재생** | `▶ PLAY` OSD + 시작 순간 글리치 1회 → 전 클론 선명도 상승 | Step 3: 하이라이트 연출 |

## 4. 가독성 금지 규칙 (이펙트 상한)

1. **위치 지터 금지** — 클론 지터는 밝기/UV만. 스프라이트 위치를 흔들면 콜라이더와 어긋나 판정 오해를 유발한다.
2. **실루엣 경계 = 콜라이더** — 어떤 이펙트도 실제 판정 범위보다 크거나 작게 보이게 하면 안 된다.
3. **정체성 4색은 캐릭터/게이트 요소 전용** — 배경·장식에 사용 금지. REC 레드도 녹화 상태 전용.
4. **스캔라인/노이즈 강도 상한** — 알파 0.5 클론의 정체성 색 판별이 어려워지는 순간 강도를 낮춘다. 이펙트가 팔레트를 이기면 안 된다.
5. **포스트 프로세싱은 항상 약하게** — 그레인·비네트·색수차는 "있는 줄 모르게". 끄면 허전한 정도가 정답.

## 5. 기존 구현과의 정합 (변경 불필요 — 이 규약 위에 얹는다)

- **색으로만 정체성 구분, 크기 차등 없음** — `IdentityData._tintColor` 확정 규칙 유지. (GDD 체크리스트의 "무거운=큰 네모, 가벼운=작은 동그라미" 임시에셋 항목은 폐기된 초안 — 코드 규칙이 우선)
- **`CloneAlpha = 0.5`** — `CharacterActor` / `ClonePlayback` 동일 상수. 클론 셰이더 도입 후에도 알파 규약은 유지하고, 셰이더는 그 위에 스캔라인만 얹는다.
- **RGB는 정체성 색, 알파만 상태 조작** — `ClonePlayback.UpdateReveal`이 RGB 보존·알파 덮어쓰기 하는 기존 규약과 호환. 셰이더 프로퍼티도 이 분리를 따른다.
- **팔레트 적용 지점** — 정체성 4색 확정값은 `Assets/Data/Identities/Identity_*.asset`의 `_tintColor` 4개 값 수정으로 반영한다 (별도 작업, 미적용 상태).

## 6. 적용 로드맵

- **Step 1 (완료)** — 본 문서. 이후 만드는 모든 에셋이 이 팔레트를 참조한다.
- **Step 2 (하네스 1회 규모, Phase 3 작업 사이 원하는 시점)** — ① Identity 에셋 4색 적용 ② Global Volume(블룸+비네트+그레인) ③ 클론 고스트 셰이더(스캔라인+밝기 지터, 정체성 색은 머티리얼 프로퍼티) ④ REC 오버레이
- **Step 3 (Phase 2 룩 검증 후 폴리시)** — 되감기 VHS 노이즈, 클리어 동시 재생 하이라이트(§9.3 리플레이 연출과 통합), 패럴랙스 배경 실루엣, 스팀 캡슐 아트

## 7. AI 에셋 활용 경계

- **AI에 맡긴다**: 패럴랙스 배경 원경(방송 장비 실루엣), 타이틀/스팀 캡슐 아트, 장식 소품 — 수정 빈도가 낮은 것
- **직접 만든다 (플랫 도형)**: 캐릭터/클론, 기믹 오브젝트, 타일셋 — 가독성 직결 + 수정이 잦은 것
- AI 산출물도 본 문서의 환경 색 톤(`#101318`~`#2A303B` 저채도)에 맞춰 보정 후 사용한다.
