### 코드 설명
#### 복잡한 코드 설명
- 화면 스캔라인은 **감산**(color *= 1-strength), 클론 스캔라인은 **가산** — 화면 전체는 은은하게 어두워지는 CRT 질감, 클론은 밝게 빛나는 홀로그램으로 서로 다른 인상 유지
- 주기도 화면 7px vs 클론 4px로 분리 — 겹쳐도 모아레 없이 클론이 도드라짐
- Renderer Feature 등록은 public API가 없어 SerializedObject로 m_RendererFeatures 리스트와 m_RendererFeatureMap(localId) 두 곳을 함께 갱신해야 함 — 하나만 추가하면 에디터 재시작 시 피처 유실
