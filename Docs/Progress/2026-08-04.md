### 코드 설명
#### 컨테이너/자료구조 선택 이유
- `ContactFilter2D + 재사용 List<Collider2D>` — 매 틱 질의 할당 0 (CrumblingPlatform/KillZone 동일 패턴). 상태는 플래시 카운터 int 하나뿐 — 발사 자체가 무상태라 재시작 결정성이 구조적으로 보장.

#### 함수 설명
- `DriveGimmickTick(tick)`: RoundManager DriveGimmicks가 매 틱 호출. TickFlash(플래시 감쇠) → LaunchOccupants(검출+발사) 순.

- `ResetGimmick()`: Initialize/RestartTake/Rewind 3경로가 자동 호출.

#### 복잡한 코드 설명
- **마스크 1(라이브 전용) 고정**: 클론은 Kinematic MovePosition 재생이라 속도 발사가 물리적으로 불가능하고 불필요 — 라이브 시절 발사 궤적이 기록되어 재생이 자동 재현한다. CrumblingPlatform의 513과 다른 이유를 주석으로 못박음(상태 이력 재현 기믹만 513).

- **트램펄린 사양**: 패드 위 정지(vy≈0)도 발사 조건을 통과해 매 착지마다 재발사 — 의도된 동작. 발사 다음 틱은 vy>ε라 이중 발사 없음.
