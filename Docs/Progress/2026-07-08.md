### 코드 설명
#### 컨테이너/자료구조 선택 이유
- 입력: `InputActionAsset`을 SerializeField로 참조 → 액션 맵/액션을 `FindAction`으로 조회. 단일 오브젝트 참조라 MCP 연결이 안정적이고, 신규 Input System 정석 사용
- 임시 도형: 런타임 생성 스프라이트는 도메인 리로드 시 유실되므로 **PNG 에셋으로 영속화**

#### 함수 설명
- `Awake`: Rigidbody2D 캐싱 + 액션 맵/Move/Jump 액션 조회
- `OnEnable/OnDisable`: 액션 활성/비활성 (구독 수명 관리)
- `Update`: 이동 입력 읽기, 접지 체크, 코요테/버퍼 카운터 갱신, 점프 조건 판정
- `FixedUpdate`: 수평 속도만 덮어쓰고 수직은 물리에 위임
- `Jump`: 수직 속도 리셋 후 impulse

#### 복잡한 코드 설명
- 코요테 타임(지면 이탈 직후 점프 허용) + 점프 버퍼(착지 직전 입력 기억)를 각각 카운터로 처리 → 정밀 조작 스트레스 완화(GDD 핵심 원칙)
