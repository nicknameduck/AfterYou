### 코드 설명
#### 컨테이너/자료구조 선택 이유
- **고정 배열 풀(`AfterimageGhost[8]`) + 라운드로빈 인덱스**: 잔상은 수명이 짧고 동시 수 상한이 정적(lifetime/interval=5)이라 리스트/큐 없이 고정 배열 순환으로 충분. 런타임 Instantiate/Destroy 0회 → GC 스파이크 없음
- **잔상 루트를 씬 루트에 분리 생성**: 캐릭터 자식으로 두면 잔상이 본체를 따라와 잔상이 성립하지 않는다. 캐릭터 파괴 시 `OnDestroy`에서 루트째 정리

#### 함수 설명
- `AfterimageTrail.LateUpdate`: 라이브 모드에서만 동작. 이동/렌더 반영 후 시점에 보간된 `transform.position`을 샘플링(시각 연출이므로 Rigidbody2D.position 규약 비대상). 간격(0.05s)+최소 이동 거리(0.08u) 충족 시 잔상 스폰
- `AfterimageGhost.Show`: 소스 스프라이트/flip/머티리얼/sortingOrder-1/lossyScale 복사(스쿼시·스트레치가 잔상에 남음) 후 활성화. 알파는 0.35에서 시작
- `AfterimageGhost.Update`: 수명(0.25s) 동안 알파 선형 감쇠 → 만료 시 자기 비활성화. **본체가 먼저 꺼져도(확정→Selecting) 잔상은 독립 오브젝트라 정상 소멸**

#### 복잡한 코드 설명
- **불연속 감지(`discontinuous`)**: 라이브 진입 첫 프레임과 한 프레임 2유닛 이상 이동(포탈 텔레포트/되감기)은 잔상을 잇지 않고 기준점만 갱신 — 화면을 가로지르는 찢어진 잔상 방지
- 잔상 수명을 0.25s로 짧게 잡은 이유: 클론(상시 α0.85 + 스캔라인)과 시각적으로 혼동되지 않게 하기 위함

## [시간 미기록] 클론 점선 외곽선 점멸 (CloneGhost.shader)

### 완료된 작업
- `Assets/Art/Shaders/CloneGhost.shader` — 점선 외곽선 + 점멸 추가. 프로퍼티 3종 신설: `_OutlineWidth`(UV 0.08) / `_OutlineDashCount`(변당 6) / `_OutlineBlinkSpeed`(2Hz). CBUFFER(UnityPerMaterial)에 추가해 SRP Batcher 호환 유지
- 검증: 셰이더 컴파일 에러 0 / 플레이 모드 실측 — 클론 확정→재생 흐름에서 CloneGhost 머티리얼 정상 적용, 스태거 페이드인 중(α0) 외곽선 미노출, 8배 확대 테스트 스프라이트로 점멸 on/off 캡처(`clone-outline-blink-on.png` / `clone-outline-blink-off.png`)

### 코드 설명
#### 복잡한 코드 설명
- **외곽선은 색만 바꾸고 알파는 유지** — `rgb = lerp(rgb, baseColor.rgb * 0.45, outlineMask)`. 알파에 더하면 스폰 은폐(α0) 클론 자리에 외곽선만 떠 보인다(스캔라인 가산항과 같은 원칙)
- **외곽선 색 = 몸통 색 × 0.45** — 아트 디렉션 "외곽선은 몸통 색 어두운 톤, 순수 검정 금지" 준수. 정체성별 색 구분이 외곽선에도 유지됨
- **점멸은 스텝 사각파(70% 듀티)** — 연속 sin이면 경계가 뭉개져 점멸로 안 읽힘(지터 스텝화와 같은 이유)
- **둘레 좌표**: 좌우 밴드는 uv.y, 상하 밴드는 uv.x — 모서리 대각선에서 점선 위상이 바뀌는 미세 아티팩트 있음(8배 확대에서만 식별, 실제 캐릭터 크기 ~42px에선 비가시)
