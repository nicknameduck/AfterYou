## [시간 미기록] 벽점프 락아웃 수정 (Major 잔존 버그)

### 완료된 작업
- `Assets/Scripts/Player/PlayerController.cs` — 벽점프 무효화 2경로 수정
  - 벽점프 임펄스의 수평 성분이 다음 FixedUpdate의 수평 덮어쓰기로 즉시 소멸하던 문제
  - 벽 방향 키 홀드 중 점프 시 다음 프레임에 즉시 재부착되어 점프가 무효화되던 문제
- 컴파일 확인: Unity 콘솔 에러 0건

### 코드 설명
#### 컨테이너/자료구조 선택 이유
- 별도 상태 enum 없이 `float _wallJumpLockoutCounter` 카운터 하나로 처리 — 기존 코요테/점프 버퍼 카운터와 동일한 패턴이라 코드 일관성이 유지되고, 락아웃은 "남은 시간"이라는 단일 정보만 필요하다.

#### 함수 설명
- `Update()` — 접지 체크 직후 락아웃 카운터를 감소시키고, 접지 시 즉시 0으로 해제한다(락아웃 중 착지하면 수평 입력이 무시되는 구간 최소화). 벽점프 성공 시 `_wallJumpLockoutCounter = _wallJumpLockout(0.15s)` 설정.
- `UpdateWallAttach()` — **부착 branch만** 락아웃 중 차단. 이탈 경로(반대 입력/접촉 상실)는 그대로 두어 매 틱 재검증(자가 치유) 규약을 유지한다.
- `FixedUpdate()` — 락아웃 중에는 수평 속도 덮어쓰기를 건너뛰어 벽점프 임펄스(벽 반대 방향 튕김)를 보존한다. 수직은 기존대로 물리에 위임.

#### 복잡한 코드 설명
- 접지 시 락아웃 즉시 해제가 카운터 감소보다 먼저 오는 이유: 같은 프레임에 `UpdateWallAttach`가 신선한 카운터 값을 봐야 하므로, 락아웃 갱신은 접지 체크 직후 · `UpdateWallAttach()` 호출 전에 위치한다.
