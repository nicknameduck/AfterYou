### 코드 설명
#### 자료구조 선택 이유
- 겹침 쌍 = 재사용 `List<(Collider2D live, Collider2D clone)>` — 매 FixedUpdate 순회하므로 GC 회피. 역순 순회로 제거 중 인덱스 안전

#### 복잡한 코드 설명
- **타이밍 불변 원칙**: "늦게 스폰"은 궤적 전체를 밀어 압력판 협력 타이밍을 깨뜨림 → 클론은 tick 0부터 정확히 재생하고 **알파만 늦게** 올림 (`UpdateReveal`)
- **분리 마진 0.05**: 겹친 채 IgnoreCollision을 복구하면 솔버가 라이브를 홱 튕겨냄 → 살짝 떨어진 뒤 복구
- **RestartTake에도 전체복구 추가** (에이전트 판단, 타당): EnterSelecting을 거치지 않고 SelectCharacter로 직행하는 경로라 복구 누락 시 쌍이 중복 누적됨
- **복구 누락 = 최대 리스크**: 남으면 이후 "클론 밟기"가 영영 안 됨 → EnterSelecting/Rewind/ConfirmClone/RestartTake 4개 진입점 전부에서 전체복구
