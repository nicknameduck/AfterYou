## 2026-07-22 — Phase 3-3 환경 기믹 5종 1회차 (72/100)

같은 실수를 반복하지 않기 위한 패턴 3가지:

1. **레벨 프리팹 좌표를 씬 상주 지형과 대조하지 않음.** SampleScene에는 `=== ENVIRONMENT ===/Ground`(top y=-2.5, x[-12,12])가 레벨과 무관하게 상주한다. 새 레벨 프리팹의 지형/기믹 y좌표는 반드시 이 씬 바닥 기준으로 배치하고, "바닥 아래 배치"(낙하 구멍 등)가 필요하면 씬 상주 지형과의 관계를 먼저 설계해야 한다. 기존 레벨(Level_1_1 PressurePlate y=-2.65)이 좌표 기준의 실례다.
2. **"중첩 프리팹 인스턴스 배치"를 Generator가 수작업 YAML 위험을 이유로 bake 복사로 대체.** manage_prefabs modify_contents의 create_child + source_prefab_path가 중첩 인스턴스를 공식 지원한다 — 수작업 YAML이 유일한 방법이 아니다. 스펙의 구조적 요구(재사용성)는 기능 동작과 별개의 계약이므로 임의 편차 금지.
3. **컬렉션 순회 중 상태 전환 메서드 호출.** DriveGimmicks 루프 안에서 KillZone이 RestartTake를 호출해 리셋 후 나머지 기믹만 한 번 더 구동됨(킬존 배열 위치 따라 1틱 desync). 순회 중 라운드 상태를 바꾸는 콜백은 플래그만 세우고, 처리 자체는 루프 밖(틱 증가 이전)에서 실행한다.
